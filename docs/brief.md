<direction>
风格：方案 D。A「观测者的显像管」与 C「世界线一镜到底」为主，B「Riso 双色印刷」点缀。
- A：CRT 仪器。荧光绿 #5cf2b0 = 观测者，琥珀 #ffb347 = 机器读数，青 #7fd8ff = 理论，红 #ff5a52 = 矛盾。桶形畸变、扫描线、余晖、泛光。
- C：沿被选中的世界线飞行，z 轴是时间。橙红 = 被选中的线，冰蓝 = 未被观测的分支（带波动，即波函数）。每两拍分叉一次，按黄金角排开。
- B：荧光粉 + 蓝双色网点套印，两版错位，错位收敛到零 = 收束。
歌词：逐字出现在演唱的那一帧；大字；字体按语义分配（明朝 = 神/世界/绝对，粗黑 = 观测者/自我，UD 明朝 = 时间/理论，Meiryo = 假名，MS 黑体 = 片假名与机器，Arial Black = ０１，细明朝 = 助词与括号），一句里字体、字号有节奏地变化。不加中文字幕。
公式全部是真 LaTeX（latex + dvisvgm 编译成字形轮廓），按书写顺序逐字形显现。
动画用缓动或闭式弹簧；镜头始终在推、拉、跟随。转场从画面内容里长出来：
- A→C「潜入」：镜头推进示波器的光点，光点开孔，里面是世界线。
- C→A「浮出」：世界线前沿的写入光点缩成 CRT 光点，屏幕从光点里展开。
- C→B「门」：世界线前方出现一道门框，冲到镜头前，门里是印刷品。
- B→A / B→C「扫描」：一道电子束自上而下扫过，把印刷页扫进显像管。
禁止：居中大字加渐变背景的默认画面；所有元素同时淡入淡出；满屏小字；无意义的边框和角标；把「収束」表现成「结束」。
</direction>

<build>
1. 画面：单个 index.html + src/film/*.js，Canvas 2D 绘制内容，WebGL 后期（CRT 与 Riso 两套着色器）；3D 为手写透视投影。不用外部图片和素材。
2. 页面暴露 window.render(t)，画出第 t 秒；所有画面只由 t 算出来，随机数带固定种子，不用计时器，帧和帧之间不保存状态。逻辑坐标 1920×1080，画布按视口尺寸缩放（模糊半径、网点尺寸、扫描线一起缩放），换 4K 不改代码。
3. 渲染：Playwright 多进程分段调用 render(t) 截图，ffmpeg 拼接并混入原曲。
4. 声音：原曲直接混入，AAC 320k。
5. 自检：只在必要时出低分辨率（960×540）静帧检查，不渲视频。
</build>
